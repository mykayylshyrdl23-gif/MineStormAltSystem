# MineStormAltingSystem

Sensitivity-based alt detection for Spigot/Paper, powered by GrimAC.

| Command | Permission | Description |
|---|---|---|
| `/alt <player>` | `minestorm.alt` | Sensitivity + suspected alts |
| `/altreport` | `minestorm.altreport` | All groups sharing a sensitivity |
| `/alttoggle` | `minestorm.togglealerts` | Toggle your own alerts |

Staff receive join alerts with `minestorm.alerts`.

## Building
Nothing to run locally: push to GitHub and the **Build** workflow compiles the plugin.
Download the jar from **Releases** (pushes to `main`/`master`) or from the run's **Artifacts**.
